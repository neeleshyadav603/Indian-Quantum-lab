How to Use

Drag gates from the palette and drop on any qubit wire at any time step.

CNOT gate: Click CNOT in palette, then click control qubit, then target qubit at the same time step.

Right-click any gate on the circuit to remove it.

Real-time simulation: State vector and probabilities update automatically.

Installation Instructions

Windows ▼
  1. Download the .exe installer from the button above
  2. Run the installer and follow the setup wizard
  3. If Windows SmartScreen appears, click "More info" then "Run anyway"
  4. Launch from Start Menu or Desktop shortcut
  5. First launch requires internet for license verification (one-time only)
Linux (Ubuntu/Debian) ▼
  1. Download the .AppImage file
  2. Make it executable: chmod +x IndianQuantumLab-2.4.1.AppImage
  3. Run: ./IndianQuantumLab-2.4.1.AppImage
  4. Optionally integrate with desktop using AppImageLauncher
  5. For system-wide installation, move to /opt/indian-quantum-lab/
macOS ▼
  1. Download the .dmg disk image
  2. Open the DMG and drag "Indian Quantum Lab" to Applications folder
  3. On first launch, right-click the app and select "Open" (bypass Gatekeeper)
  4. Grant permission for network access if prompted
  5. For Apple Silicon (M1/M2/M3), the app runs natively
